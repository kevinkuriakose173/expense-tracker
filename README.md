# MERN Expense Tracker Application

A full-stack expense tracker application built using the MERN (MongoDB, Express.js, React.js, Node.js) stack. This project allows users to manage their expenses with a secure user authentication system and a seamless interface for creating, reading, updating, and deleting expense data.

---

## Features

### 🔐 User Authentication and Management
- Secure user registration and login system using **bcryptjs** for password hashing.
- **JWT (JSON Web Tokens)** for secure authentication and authorization.

### 📝 Expense Management
- Users can perform full CRUD operations:
  - **Create** new expenses.
  - **Read** and view all expenses.
  - **Update** existing expenses.
  - **Delete** expenses.

### 📊 Balance Trends Visualization
- Displays balance trends over time using **Chart.js** for an interactive and visual representation of spending habits.

### 🌐 REST API
- A robust API built with **Express.js** and **Node.js**.
- Handles all backend logic and communicates with a **MongoDB** database for persistent storage.

### 💻 Frontend
- An intuitive and responsive user interface built with **React.js** for managing expenses.

---

## Technologies Used

- **Frontend:** React.js, Chart.js
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Authentication:** bcryptjs, JWT
